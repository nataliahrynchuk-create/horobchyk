# Горобчик — ретро-тамагочі для задач

Веб-гра-трекер: записуй задачі на день, відмічай виконані, і вони «летять» Горобчику як їжа.
Від кількості виконаних задач він росте від яйця до дорослого горобця (100 задач).

## Можливості
- список задач дня; виконана задача зникає після того, як Горобчик її з’їв
- ситість на екрані завжди показує виконані задачі дня
- 6 етапів росту, два вигляди: піксель-контур і малюнок
- «Погладити» і «Погратись» (5 випадкових ігор, серед них тектонік)
- ретро-звуки, кнопка «Повернути до яйця»

## Запуск локально
Відкрий `index.html` у браузері. Збирати нічого не треба.

## Публікація на GitHub Pages
1. Створи репозиторій на github.com (наприклад, `horobchyk`), публічний.
2. Завантаж сюди всі файли з цієї папки (**Add file → Upload files**).
3. Відкрий **Settings → Pages**, у Source вибери **Deploy from a branch**, гілка `main`, папка `/ (root)`, натисни Save.
4. Через хвилину гра буде за адресою `https://<твій-логін>.github.io/horobchyk/`.

## Примітки
- Прогрес зберігається в браузері (localStorage) на конкретному пристрої.
- Шрифт екрана підвантажується з Google Fonts, без інтернету підставиться запасний.
